# ТВ-СТАРТ

«ТВ-СТАРТ» — акционерная фирма, указанная учредителем нереализованного проекта [«Независимое телевидение Украины»](../Projects/independent-television-ukraine.md).

## Основная информация

- ID: `organization-tv-start`
- Организационная форма по источнику: акционерная фирма

## Телевизионный проект

По [Борису Скуратовскому](../Sources/mediasat-2016-01-20-history-of-ukraine-television-2.md), фирма учредила проект телестудии, зарегистрированный к началу 1991 года. Президент фирмы Юрий Каплин представлял планы будущего вещания. Эфирный запуск проекта не состоялся.
